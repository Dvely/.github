# Dvely 로고 패키지

## 디자인
Qeploy 로고와 한 가족으로 보이도록 같은 규칙으로 그렸습니다.
- 심볼: 곧은 기둥과 둥근 몸통으로 된 D 고리 + 바깥으로 이어지는 배포 화살표. Qeploy 심볼과 같은 90 × 90 좌표계, 같은 획 두께(18), 같은 틈(9), 같은 꺾쇠 화살표를 씁니다.
- 워드마크: Manrope ExtraBold, 112px, 자간 −3.6px. Qeploy 워드마크와 같은 크기와 기준선입니다.

예전 로고(학사모 + 필기체 D)를 대체합니다.

## 색상
- Violet: #7C3AED
- Ink: #0B0C12
- Lavender: #C4A7FF
- White: #FFFFFF

## 파일 안내
- Dvely-Logo-Primary.svg / .png: 밝은 배경용 가로형 로고
- Dvely-Logo-Dark.svg / .png: 어두운 배경용 라벤더 심볼 + 흰색 글자
- Dvely-Logo-Black.svg / .png: 잉크색 단색 로고
- Dvely-Logo-White.svg / .png: 흰색 단색 로고
- Dvely-Symbol-*.svg / .png: 심볼 단독 버전
- Dvely-App-Icon.svg / -192·512·1024.png: 둥근 사각형 배경을 포함한 아이콘
- Dvely-GitHub-Avatar.svg / -1024.png: GitHub 조직 프로필 사진용. GitHub가 모서리를 잘라내므로 배경을 정사각형으로 꽉 채웠습니다
- favicon.svg: 브라우저 테마에 반응하는 벡터 파비콘
- favicon-16/24/32/48/64.png 및 favicon.ico: 고정 크기 파비콘
- Dvely-Preview.png: 흰 배경 미리보기 이미지

가로형 PNG는 1804 × 576px, 심볼 PNG는 512 × 512px입니다.
로고와 심볼 PNG의 배경은 투명합니다. Preview와 GitHub Avatar에는 배경이 있습니다.
SVG의 워드마크는 윤곽선으로 변환되어 있어 글꼴을 설치하지 않아도 같은 모양으로 표시됩니다.

## 사용 규칙
1. 웹 헤더에는 가로형, 좁은 영역·파비콘·앱 아이콘에는 심볼을 사용하세요.
2. 심볼 높이의 1/4 이상 보호 여백을 확보하세요.
3. 가로세로 비율을 유지하고, 회전·그림자·윤곽선 효과를 임의로 추가하지 마세요.
4. 16px은 파비콘용이며 일반 인터페이스에서는 24px 이상을 권장합니다.

## GitHub 조직 프로필 사진 바꾸기
GitHub API로는 조직 프로필 사진을 바꿀 수 없어서 직접 올려야 합니다.
조직 Settings → Profile → Profile picture에서 `Dvely-GitHub-Avatar-1024.png`를 업로드합니다.

이 패키지는 로고 디자인 제안입니다. 별도의 상표 유사성·등록 가능성 조사는 포함하지 않았습니다.
